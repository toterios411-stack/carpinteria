# 🪵 Sistema de Gestión para Taller de Carpintería (Sprint 3)

Proyecto académico desarrollado para el control integral de operaciones en un taller de carpintería, abarcando gestión de usuarios (RBAC), clientes, catálogo de muebles, pedidos, **Módulo 4 (Proveedores y Compras)** y **Módulo 5 (Reportes y Estadísticas)**[cite: 1].

---

## 🚀 Requisitos y Tecnologías
* **Lenguaje:** Python 3.12+[cite: 6]
* **Base de Datos:** SQLite3 (`carpinteria.db`)[cite: 6]
* **Interfaz Gráfica:** Tkinter[cite: 6]
* **Control de Versiones:** Git & GitHub (con TAGs `v3.0`)[cite: 6]
* **Pruebas Unitarias (PUN):** `unittest`[cite: 1, 6]
* **Documentación (PDO):** `pdoc`[cite: 1, 6]
